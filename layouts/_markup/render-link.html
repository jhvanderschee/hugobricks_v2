{{- /* Link render hook. Plain, predictable anchors, and deliberately no `class` or `id` — those arrive from a kramdown-style attribute list written after the link: [Get started now](/get-started/){:.button} A render hook only ever sees its own node, so it cannot read the text that follows it. `inline_attributes.html` moves that `{: … }` onto the anchor once the paragraph is html; this file's job is to guarantee the shape that pass expects to find. A link whose destination is a local raster image — the lightbox pattern, `[![](/photo.jpg)](/photo.jpg)` — gets a resized webp rendition instead of the full-weight original, mirroring what the gallery shortcode links to. @context {link} . @returns {string} one */ -}} {{- $href := .Destination -}} {{- with resources.GetMatch $href -}} {{- if and (eq .ResourceType "image") (ne .MediaType.SubType "svg") -}} {{- $href = (.Fit "1600x1600 webp q50").RelPermalink -}} {{- end -}} {{- end -}} {{ .Text }} {{- /* no trailing newline: a render hook writes inline content */ -}}
