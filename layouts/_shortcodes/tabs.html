{{- /* A tabbed panel. Each tab is a run of markdown opening on an `## Heading`, separated by `---` — the heading is the tab, the rest is its panel: {{< tabs >}} ## First tab Its content. --- ## Second tab More content. {{< /tabs >}} The `---` here never reaches `section_map.html`: the shortcode consumes its inner markdown before the page is split, so a tab boundary does not become a brick boundary. Revised from the original theme: real `role="tab"` buttons with the roving tabindex and `aria-selected` that `site.js` maintains, instead of ``; the script lives there rather than inline, and without it the panels simply stack under their own headings — the tablist only shows once the script has marked the widget `ready`. @context {shortcode} . */ -}} {{- $ordinal := .Ordinal -}} {{- $parts := slice -}} {{- range $part := split .Inner "---" -}} {{- with trim $part "\n\r\t " -}} {{- $parts = $parts | append . -}} {{- end -}} {{- end -}} {{- if not $parts -}} {{- warnf "tabs: the shortcode on %q is empty — write `## Heading` runs separated by `---` inside it" .Page.File.Path -}} {{- end -}}
{{- range $i, $part := $parts -}} {{- $title := replaceRE `<[^>]*>` "" (or (index (findRE `(?s)]*>.*?` (markdownify $part) 1) 0) "") -}} {{- if not $title -}} {{- $title = printf "Tab %d" (add $i 1) -}} {{- warnf "tabs: a tab on %q has no `## Heading` to name it — labelled %q" $.Page.File.Path $title -}} {{- end -}} {{- end -}}
{{- range $i, $part := $parts }}
{{ markdownify $part }}
{{- end }}
