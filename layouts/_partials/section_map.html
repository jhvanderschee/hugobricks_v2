{{- /* Splits a page's content into sections on its horizontal rules and decides which brick renders each one, using the rules in `params.sections`. This is the single source of truth for that decision: `sections_logic.html` ranges over the result to render the page, and `site/header.html` reads the first entry to find out whether the page opens with a brick that paints a full-bleed backdrop — which is what makes a transparent banner safe. A rule looks like: - title: header # -> layouts/_partials/sections/header.html has: img.background # -> the section holds a background image not_has: h2 # -> and holds no h2 is: :first-child # -> and is the first section not_is: :only-child # -> and is not the only one All four conditions are optional and every one that is set has to hold. A rule with none of them set is skipped, because it would claim every section. `has` / `not_has` take a comma-separated selector list — a tag, a `.class` or an `#id`, in any combination of a tag with one of the two, each optionally suffixed with `:first-child` or `:last-child` for the element the section opens or closes on, see `section_has.html`. Everything listed must be present, and `not_has` is the exact negation of `has`: `not_has: h1, img.background` means "not (an h1 *and* a background image)", not "neither of them". The classes are the ones the markdown put there, through the attribute lists `inline_attributes.html` hoists: `![](/photo.jpg){:.background}` is what `img.background` matches. `is` / `not_is` take a position — `:first-child`, `:last-child`, `:only-child`, `:nth-child(n)` (1-based), optionally wrapped in `:not(…)`, see `section_position.html`. Rules are evaluated top to bottom and the first match wins; a section matching no rule falls back to `wide`, the plain prose brick — the safest thing to do with markdown nobody claimed is to set it at reading measure. The markdown can overrule all of it: a divider written as `---.small` (instead of `---`) still splits, and forces the section it opens to the `small` brick, rules unheard. Any brick name works — `---.intro`, `---.image-alt` — and a name without a partial falls back to `wide` with the same warning a rule would get. Opening the page itself with one forces the first section. The typographer writes such a line into the html as `

—.small

`, which is what the normalisation below looks for. A named divider that opens an *empty* section is an include: ---.cta --- pulls in `content//bricks/cta.md` and renders it as the `cta` brick — shared furniture like the closing call to action or the address card, written once per language and dropped into any page. The section count and the `is` positions are settled before the pull, so an include is one section like any other. A name with no page behind it warns and renders the empty section it wrote, where the gap is easier to spot than a page that quietly shortened itself. Call it through `partialCached` — the page renders it twice. @context {page} . @returns {slice} one dict per section: Name, Content, Index, Forced */ -}} {{- $page := . -}} {{- $rules := site.Params.sections | default slice -}} {{- /* `---.small` is no thematic break to goldmark: it leaves the page as a paragraph reading `—.small` (or `---.small` with the typographer off). Fold it into a plain divider carrying its brick name, so the split below treats it as any other `---`. */ -}} {{- $content := partial "inline_attributes.html" $page.Content -}} {{- $content = replaceRE `

(?:—|—|-{3,})\s*\.([a-zA-Z0-9][a-zA-Z0-9_-]*)

` "
" $content -}} {{- $sections := slice -}} {{- range $part := split $content "
" -}} {{- with trim $part "\n\r\t " -}} {{- $sections = $sections | append . -}} {{- end -}} {{- end -}} {{- $count := len $sections -}} {{- $out := slice -}} {{- range $i, $html := $sections -}} {{- $name := "wide" -}} {{- $matched := false -}} {{- $forced := false -}} {{- /* A divider that names its brick has already decided. */ -}} {{- if hasPrefix $html ".*` "$1" $html -}} {{- $html = trim (strings.TrimPrefix (printf "" $name) $html) "\n\r\t " -}} {{- $matched = true -}} {{- $forced = true -}} {{- /* Named but empty: an include. The shared page's markdown has not been through the hoisting this page's own content got at the top, so it gets its own pass. */ -}} {{- if not $html -}} {{- with site.GetPage (printf "/bricks/%s" $name) -}} {{- $html = trim (partial "inline_attributes.html" .Content) "\n\r\t " -}} {{- else -}} {{- warnf "section_map: `---.%s` opens an empty section and there is no content//bricks/%s.md to fill it" $name $name -}} {{- end -}} {{- end -}} {{- end -}} {{- range $rule := $rules -}} {{- if not $matched -}} {{- $match := true -}} {{- $tested := false -}} {{- /* has / not_has: what the section is made of */ -}} {{- with $rule.has -}} {{- $tested = true -}} {{- $match = and $match (partial "section_has.html" (dict "Html" $html "Selectors" .)) -}} {{- end -}} {{- with $rule.not_has -}} {{- $tested = true -}} {{- $match = and $match (not (partial "section_has.html" (dict "Html" $html "Selectors" .))) -}} {{- end -}} {{- /* is / not_is: where the section sits among the sections of this page */ -}} {{- with $rule.is -}} {{- $tested = true -}} {{- $match = and $match (partial "section_position.html" (dict "Selector" . "Index" $i "Count" $count)) -}} {{- end -}} {{- with $rule.not_is -}} {{- $tested = true -}} {{- $match = and $match (not (partial "section_position.html" (dict "Selector" . "Index" $i "Count" $count))) -}} {{- end -}} {{- if not $tested -}} {{- warnf "section_map: rule %q sets no condition and would claim every section — skipped" $rule.title -}} {{- else if and $match $rule.title -}} {{- $name = $rule.title -}} {{- $matched = true -}} {{- end -}} {{- end -}} {{- end -}} {{- if not (templates.Exists (printf "_partials/sections/%s.html" $name)) -}} {{- warnf "section_map: missing partial %q, falling back to sections/wide" $name -}} {{- $name = "wide" -}} {{- end -}} {{- $out = $out | append (dict "Name" $name "Content" $html "Index" $i "Forced" $forced) -}} {{- end -}} {{- /* The image bricks zig-zag: every other one sits on a tinted band. Which phase a page starts on depends on what it opens with. After an `intro` the first band is tinted, so the grey breaks up the white the intro ends on; after a full-bleed `header` the first image stays white, so a tinted band does not butt straight up against the hero. That is how the theme's own pages are built — the home page opens `intro`, `image alt`, `image`, the demo pages open `header`, `image`, `image alt`. It cannot be written as a `has`/`is` rule, because it depends on the other sections rather than on this one, so it is a pass over the routed list. The two names are one brick with two faces: a rule naming either of them feeds the same alternation. */ -}} {{- $pair := slice "image" "image-alt" -}} {{- $tinted := false -}} {{- with $out -}} {{- $tinted = eq (index . 0).Name "intro" -}} {{- end -}} {{- $zigzag := slice -}} {{- range $out -}} {{- $section := . -}} {{- if in $pair $section.Name -}} {{- /* A forced face is kept and re-anchors the phase, so the sections after it keep alternating from the face it chose. */ -}} {{- if $section.Forced -}} {{- $tinted = eq $section.Name "image-alt" -}} {{- end -}} {{- $section = merge $section (dict "Name" (cond $tinted "image-alt" "image")) -}} {{- $tinted = not $tinted -}} {{- end -}} {{- $zigzag = $zigzag | append $section -}} {{- end -}} {{- return $zigzag -}}
