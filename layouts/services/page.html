{{- /* A single service. Services do not go through `section_map.html` the way an ordinary page does: like a blog post, a service is one article rather than a stack of bricks, and what makes it one is where it lives, not what is written in it. So the `post` brick renders the page whole — a service page and a post page are the same shape, which is how the original theme builds them too — and the call to action every service closes on is added after it. That call to action is written once, in `content//bricks/cta.md`, and shared by every service. Its content has to go through `inline_attributes.html` here, because the page being rendered is not the one the markdown came from: `section_map.html` hoists the attribute lists for an ordinary page, and nothing has hoisted these. */ -}} {{ define "sections" }} {{- partial "sections/post.html" (dict "Content" .Content "Name" "post" "Index" 0 "Page" .) -}} {{- with site.GetPage "/bricks/cta" -}} {{- partial "sections/cta.html" (dict "Content" (partial "inline_attributes.html" .Content) "Name" "cta" "Index" 1 "Page" $) -}} {{- end -}} {{ end }}
