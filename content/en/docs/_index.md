This documentation is written to help you understand how you can/should use Hugobricks (v2). It does so by describing all available bricks and shortcodes with relevant code examples. If you want to learn more about the philosophy behind Hugobricks, please read the [readme file](https://github.com/jhvanderschee/hugobricks_v2#readme) in the repository.

The v2 version is a complete make-over of the way the bricks work. They no longer use `.Inner`, but use a rule based detection system. Bricks are now seperated by three minus signs (a hr), like this `---`. The goal of v2 is to make the markdown cleaner and easier to edit. This results in more readable content and less build errors. The new version uses Kramdown-style custom classes in images and links and uses this instead of shortcodes for things like buttons. Finally the new version fully supports https://pos.usecue.com, the commission free way of paying in the EU.

Hugobricks is aiming to be the Ultimate Hugo Theme... and this v2 version is another step in that direction.
