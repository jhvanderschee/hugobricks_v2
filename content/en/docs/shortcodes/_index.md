You might wonder what the difference is between a Hugo 'shortcode' and a Hugo 'brick'. Shortcodes place reusable content in an inline way, somewhere inside a section. Bricks are complete sections of a page. An example of a shortcode is a form; an example of a brick is a 'Call to action brick'.

Below you find a list of the available shortcodes.

- [Breadcrumbs](/docs/shortcodes/breadcrumbs/)
- [Button](/docs/shortcodes/button/)
- [Contact buttons](/docs/shortcodes/contactbuttons/)
- [Contact form](/docs/shortcodes/contact-form/)
- [CTA form](/docs/shortcodes/cta-form/)
- [F.A.Q.](/docs/shortcodes/faq/)
- [Social buttons](/docs/shortcodes/socialbuttons/)

Three more are collection shortcodes, which render a data file as the grid of a brick: `{{</* features */>}}`, `{{</* reviews */>}}` and `{{</* pricing */>}}`. There is also `{{</* newsletterform */>}}` and `{{</* openinghours */>}}`.
