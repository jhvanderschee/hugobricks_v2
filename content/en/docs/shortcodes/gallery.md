title: Gallery
---

The gallery used to be a shortcode that turned a folder into a grid. It is a plain markdown list now — one list item per image, each a thumbnail linking to the full-size file:

```
- [![](/uploads/gallery/01.jpg)](/uploads/gallery/01.jpg)
- [![](/uploads/gallery/02.jpg)](/uploads/gallery/02.jpg)
- [![](/uploads/gallery/03.jpg)](/uploads/gallery/03.jpg)
```

You can see it in action at the bottom of the [elements page](/elements/). Writing the list out means the order is yours to choose, and the alt text of every image is yours to write.
