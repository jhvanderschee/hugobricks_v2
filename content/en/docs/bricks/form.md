The form brick is a short form on its own, in a narrow column — a call-to-action form or a newsletter signup. You can see it in action on the [get started page](/get-started/).

## Use this brick

To use this brick you only need the [ctaform shortcode](/docs/shortcodes/cta-form/):

```
{{</* ctaform */>}}
```

A heading above it is typical but not required. The fields of the form are defined in `data/<lang>/ctaform.yaml`. You can force the use of this block by writing:

```
---.form
```
