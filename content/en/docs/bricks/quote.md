The quote brick is a pulled quotation with its attribution, optionally over a backdrop image. You can see it in action on the [images page](/images/) and on all four example pages.

## Use this brick

To use this brick you should open the section with a blockquote. An attribution after it and an image anywhere in the section (it becomes the backdrop) are optional:

```
![](/uploads/photos/hike/hike4.jpg)

> "Ready to build your next project with Hugobricks?"

— Lorem ipsum dolor
```

You can force the use of this block by writing:

```
---.quote
```
