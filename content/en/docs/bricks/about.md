The about brick is a personal introduction: a round portrait, an h1, a paragraph of body copy and a row of social links. You can see it in action on the [about page](/about/).

## Use this brick

Note that the portrait in this brick is a plain markdown image; the brick makes it round. To use this brick you should use an image with a Kramdown-style custom class 'about', like so:

```
![This is not me](/uploads/photos/avatars/2.jpeg){:.about}
```

You can force the use of this block by writing:

```
---.about
```
