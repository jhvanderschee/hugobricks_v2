Having a nice 404 (page not found) page is always nice. This brick provides one. You can see it in action on the [custom 404 page](/404/).

## Use this brick

To use this brick you should use an image with a Kramdown-style custom class '404', like so:

```
![](/uploads/illustrations/cuate/error.svg){:.404}
```

You can force the use of this block by writing:

```
---.error404
```
