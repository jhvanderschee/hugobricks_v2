Having a nice 404 (page not found) page is always nice. This brick provides one. You can see it in action on the [custom 404 page](/404/).

## Use this brick

A page routes to the `error404` brick when it is a single section holding an illustration, a heading and a link back home. The whole page looks like this:

```
---
title: Page not found (404)
---

![](/uploads/illustrations/cuate/error.svg){:.404}

# Oops! Something went wrong!

{{</* button "Back to home" "/" */>}}
```
